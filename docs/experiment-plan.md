# VLM Dance 実験計画

## 研究質問

1. VLMはダンス動画の観察可能な動作をどの程度正確に記述できるか。
2. 静止画の集合と時系列フレームで、動作遷移や反復の記述に差が出るか。
3. 音声・音楽・場面情報の追加で、観察と意味推定はどう変わるか。
4. VLMは映像から確認できない意図や感情を断定せず、不確実性を示せるか。
5. モデルやプロンプトを変更したとき、結果はどの程度安定するか。

## 仮説（未検証）

- 動作記述と意味推定を別々に評価すると、VLMの得意・不得意を明確にできる。
- 時系列情報は動作の遷移や反復の記述に役立つ可能性がある。
- 文脈は推定を改善する一方、先入観による過剰解釈を増やす可能性もある。
- タイムスタンプ付きの根拠を要求すると、結果の検証可能性が高まる可能性がある。

## MVPデータ

- 利用許諾とライセンスを確認できる短いダンス動画を5〜20本選ぶ。
- 長さ、解像度、カメラ視点、遮蔽、ソロ／グループなどを記録する。
- 学習用と評価用のデータを混在させない。
- 動画本体を公開できない場合は、権利上許される範囲でメタデータと注釈を管理する。

## 比較条件

- A：数枚のフレームのみ
- B：時系列順のフレーム
- C：時系列フレーム + 音声・音楽情報（利用可能な場合）
- D：時系列フレーム + 明示された場面説明

モデルが音声や動画を直接処理できない場合は、変換方法を記録する。比較では動画、タスク、評価基準をできるだけ揃える。

## 標準タスク

1. 動作記述：身体部位、動作、方向、姿勢
2. 時間構造：開始・終了、反復、動作の切り替え
3. 空間関係：身体の向き、移動方向、他者との相対位置
4. 音楽との関係：音声がある場合に限り、動作とリズムの対応を推定
5. 解釈仮説：表現意図や様式を候補として挙げ、根拠と不確実性を示す
6. 保留：映像だけでは分からない事項を明示する

## 実験記録

動画IDと時間範囲、データ版、モデル名・版、プロンプト版、フレーム抽出方法、解像度、音声前処理、生成設定、実行日時、出力、エラー、処理時間、評価結果を保存する。

## 成功条件

初期成功は「VLMがダンスを理解した」と証明することではない。別の人が同じデータと設定で実験を再実行し、観察記述と意味推定を比較できる状態を作ることである。
