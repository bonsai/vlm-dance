# VLM Dance 評価指標

## 基本原則

動作の検出・記述と、意味や意図の解釈を分けて評価する。ダンスの解釈には文化や文脈が関わるため、すべての例に単一の正解ラベルがあるとは限らない。

## 指標

### 1. 観察記述の正確さ
- 身体部位、方向、姿勢、移動の事実誤認
- 映像に存在しない動作を記述する割合
- 重要な動作の見落とし
- 時間範囲のずれ

### 2. 時系列の理解
- 動作順序の正確さ
- 開始・終了時刻の誤差
- 反復回数の一致
- 動作遷移の見落としや誤検出

### 3. 根拠づけ
- 主張に対応するフレームや時間範囲があるか
- 根拠が主張を実際に支持しているか
- 根拠のない詳細を付け加えていないか

### 4. 解釈の品質
- 複数注釈者による判断との一致
- 複数の妥当な解釈を保持できるか
- 文脈を変えた際に根拠に沿って推定が変わるか
- 文化的意味や感情を過度に断定しないか

### 5. 不確実性
- 不明な項目を適切に保留できるか
- 確信度と正答率が対応するか
- 遮蔽や画質低下で過信しないか

### 6. 再現性と運用性
- 同一設定での出力安定性
- モデル・プロンプト間の性能差
- 実行時間、コスト、失敗率
- 第三者による再現可能性

## 評価手順

1. 注釈ガイドラインを先に固定する。
2. 複数の注釈者が独立してラベル付けする。
3. 注釈者間の不一致を測り、曖昧な例を特定する。
4. モデル出力をブラインド評価する。
5. 定量指標に加え、失敗例をカテゴリ別に分析する。
6. モデル、プロンプト、データの版とともに結果を報告する。

## 失敗カテゴリ

- 身体部位や左右の取り違え
- 動作順序・時刻の誤り
- 音楽との同期を根拠なく断定
- ダンス様式や感情を根拠なく断定
- 遮蔽・画角の制約を無視
- 見えない情報を作り出す
- 適切に保留すべき例で過剰に断定

## レポートの最小要件

研究質問、比較条件、データの出典・ライセンス、注釈方法、注釈者間一致、モデルとプロンプトの版、定量結果、不確実性、代表的な成功・失敗例、制約、再現手順を記録する。
