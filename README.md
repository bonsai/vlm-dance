# VLM Dance — ダンス動画を観察・記述・評価する

Vision-Language Model（VLM）を用いてダンス動画を解析し、観察可能な動作、意味の解釈、判断の不確実性を分けて評価する研究プロジェクト。

## 目的

- 映像に見える動作を正確に記述できるか
- 時系列・リズム・動作遷移を捉えられるか
- 文脈に応じた解釈を根拠とともに示せるか
- 見えない情報や曖昧な意図を断定せず保留できるか
- 同じ入力・設定で結果を再現できるか

## body-language との関係

- [bonsai/body-language](https://github.com/bonsai/body-language)：身体表現全体、表情、手話、VTuberの仕草・LoRA研究
- bonsai/vlm-dance：ダンス動画に対象を絞ったVLM評価、注釈、実験データ

本リポジトリはまずVLMの観察・推論能力を評価する。ダンス生成やLoRA学習は、必要性を確認してから別実験として扱う。

## 評価パイプライン

1. 利用許諾を確認した動画を選ぶ。
2. 出典、ライセンス、動画区間を記録する。
3. 人間が観察可能な動作を注釈する。
4. VLMに同じタスクを与え、出力を構造化する。
5. 人間の注釈と比較し、誤り・根拠のない断定・不確実性の扱いを評価する。
6. モデル、プロンプト、フレーム抽出設定、結果を保存する。

## 原則

- **観察と解釈を分ける。** 「腕を上げた」と「喜んでいる」は異なる主張。
- **時間を保持する。** ダンスを単一フレームだけで判断しない。
- **根拠を記録する。** 可能な限りタイムスタンプやフレーム範囲を示す。
- **曖昧さを尊重する。** 意図や文化的意味は映像だけでは決められない場合がある。
- **権利とプライバシーを守る。** 利用条件、同意、保存・共有範囲を確認する。

## Status

研究設計の初期段階。評価結果が得られるまでは、VLMがダンスを理解したと結論づけない。
